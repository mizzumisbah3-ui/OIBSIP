# Infographic Design

## Overview

This project was completed as part of the **Oasis Infobyte Graphics Design Internship** under the **Graphics Design Track (Task 4).**

The objective of this project was to design an informative and visually engaging infographic that presents complex information in a simple, organized, and easy-to-understand format.

For this task, I created an infographic titled **"The State of Emerging Tech"**, which highlights the latest trends and developments in technology. The infographic covers topics such as Artificial Intelligence, Cybersecurity, Cloud Computing, Robotics, technology adoption, skill growth, and the evolution of modern computing. The design combines icons, charts, statistics, and timelines to improve readability while maintaining a professional and modern appearance.

---

## Features

- Professionally designed technology-themed infographic
- Modern and visually appealing layout
- Consistent blue and white color palette
- Clear visual hierarchy with headings and sections
- Includes statistical highlights and key insights
- Uses icons and illustrations for better understanding
- Progress bars and data visualization
- Timeline representing technological evolution
- Well-balanced spacing and typography
- High-resolution export suitable for both digital and print use
