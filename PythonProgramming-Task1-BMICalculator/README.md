# BMI Calculator

## Overview

This project was completed as part of the **Oasis Infobyte Python Programming Internship** under the **Python Programming Track (Task 1).**

The objective of this project was to develop a **BMI (Body Mass Index) Calculator** that calculates a user's BMI based on their weight and height and classifies the result into standard health categories. Body Mass Index is a widely used measure that helps determine whether a person's weight is appropriate for their height.

The application provides a simple and interactive interface where users can enter their weight and height, calculate their BMI instantly, and receive the corresponding health category. The project also includes input validation to ensure users enter valid numeric values, making the application reliable and user-friendly.

This project helped strengthen my understanding of Python programming, GUI development using Tkinter, user input handling, conditional statements, arithmetic operations, and exception handling while building a practical desktop application.

---

## Features

- User-friendly graphical interface developed using Tkinter
- Accepts user input for weight (in kilograms) and height (in meters)
- Calculates BMI using the standard Body Mass Index formula
- Displays the calculated BMI value rounded to two decimal places
- Classifies BMI into the following health categories:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- Performs input validation to prevent invalid or empty entries
- Displays appropriate error messages for non-numeric or negative values
- Provides quick and accurate BMI calculation through a simple interface

## Project Workflow

1. Launch the BMI Calculator application.
2. Enter the user's weight in kilograms.
3. Enter the user's height in meters.
4. Click the **Calculate BMI** button.
5. Calculate the BMI using the standard formula:
   **BMI = Weight / (Height²)**
6. Display the calculated BMI value rounded to two decimal places.
7. Determine the appropriate health category based on the BMI value.
8. Display the BMI result along with the corresponding health category.
9. Show appropriate error messages if invalid or incomplete input is provided.
