# Random Password Generator

## Overview

This project was completed as part of the **Oasis Infobyte Python Programming Internship** under the **Python Programming Track (Task 2).**

The objective of this project was to develop a secure and user-friendly application that generates strong random passwords based on user-defined preferences. Password security plays a vital role in protecting personal and online accounts, and this application helps users create complex passwords that are difficult to guess or crack.

The application allows users to customize the password length and select different character types, including uppercase letters, lowercase letters, numbers, and special symbols. It validates user input, ensures that the generated password satisfies the selected criteria, evaluates password strength, and provides additional features such as clipboard support and password history for improved usability.

---

## Features

- Generates strong and secure random passwords
- Allows users to choose the desired password length
- Supports multiple character types:
  - Uppercase letters
  - Lowercase letters
  - Numbers
  - Special symbols
- Ensures every generated password includes at least one character from each selected category
- Displays password strength based on length and character diversity
- Allows users to copy the generated password directly to the clipboard
- Maintains a history of recently generated passwords during the current session
- Validates user input and displays appropriate error messages for invalid entries
- Provides a clean and user-friendly graphical interface

## Technologies Used

## Project Workflow

1. Launch the application.
2. Enter the desired password length.
3. Select the character types to include in the password.
4. Click the **Generate Password** button.
5. Generate a secure password using Python's **Secrets** module.
6. Display the generated password along with its strength level.
7. Copy the password to the clipboard using the **Copy** button.
8. View the list of recently generated passwords during the current session.
9. Generate additional passwords with different settings whenever required.
