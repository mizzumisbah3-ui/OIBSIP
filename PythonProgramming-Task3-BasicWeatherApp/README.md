# Basic Weather App

## Overview

This project was completed as part of the **Oasis Infobyte Python Programming Internship** under the **Python Programming Track (Task 3).**

The objective of this project was to develop a weather application that retrieves real-time weather information for a user-specified location using the OpenWeatherMap API. The application provides users with accurate weather details such as temperature, humidity, weather conditions, and wind speed through a simple and interactive graphical user interface.

The application validates user input, communicates with the weather API to fetch live weather data, and displays the information in a clean and easy-to-understand format. It also handles common errors such as invalid city names, network issues, and incorrect API keys to ensure a smooth user experience.

---

## Features

- Fetches real-time weather information using the OpenWeatherMap API
- Allows users to search weather by entering a city name
- Displays:
  - Current temperature
  - Temperature in Celsius and Fahrenheit
  - Humidity percentage
  - Weather condition description
  - Wind speed
- Displays weather icons based on current weather conditions
- Simple and user-friendly graphical interface
- Validates user input before making API requests
- Handles API errors such as:
  - Invalid city name
  - Network connection failure
  - Invalid API key
- Displays error messages within the application instead of the terminal

## Project Workflow

1. Launch the application.
2. Enter the desired city name.
3. Click the **Get Weather** button.
4. Send an API request to OpenWeatherMap.
5. Receive and process the JSON response.
6. Display the current weather details including:
   - Temperature
   - Humidity
   - Weather condition
   - Wind speed
7. Display the corresponding weather icon.
8. Handle invalid inputs or API errors with appropriate messages.
