# Android Calculator App 📱

A clean, user-friendly, and fully functional **Android Calculator Application** developed using **Java** and **XML** in **Android Studio**. This project demonstrates Android UI development, event handling, user input processing, and implementing mathematical operations with proper error handling.

The application provides a simple calculator interface with a responsive button grid layout, allowing users to perform basic arithmetic calculations quickly and efficiently.

---

## 🚀 Features

### 🔢 Basic Arithmetic Operations
- Perform addition (+)
- Perform subtraction (-)
- Perform multiplication (×)
- Perform division (÷)
- Supports multiple operations with correct calculation priority

### 🔹 Input Management
- Number buttons from 0–9
- Decimal point support for floating-point calculations
- Clear (C) button to reset the calculator
- Backspace button to remove the last entered character
- Displays current expression and calculation results

### ⚡ Error Handling
- Handles division-by-zero scenarios
- Displays "Error" message for invalid calculations
- Prevents application crashes during rapid button clicks or incorrect input

### 🎨 User Interface
- Designed using XML layouts
- Responsive button arrangement using GridLayout
- Simple and clean calculator interface
- Easy-to-use button controls with TextView display

---

## 🛠 Technologies Used

- **Android Studio** – Development Environment
- **Java** – Application Logic
- **XML** – User Interface Design
- **GridLayout** – Calculator Button Arrangement
